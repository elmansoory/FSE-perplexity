# Pro Analyzer Advanced

نسخة تشغيلية مطورة لبرنامج تحليل أداء التزلج باستخدام Streamlit وMediaPipe.

## التشغيل
```bash
pip install -r requirements.txt
streamlit run app.py
```

## الميزات الحالية
- رفع فيديو وتحليل أولي ومتقدم للحركة
- تقسيم الأداء إلى مراحل: Preparation / Takeoff-Flight / Landing
- قياس زاوية الركبة والجذع عبر الزمن
- تصنيف الأخطاء إلى: critical / major / minor / good
- حساب أولي لـ Base Value و GOE و Technique Score
- تقدير Program Components Score بشكل تدريبي
- تنزيل تقارير JSON و Excel و TXT

## الهدف الحالي
هذه النسخة تدريبية/تحليلية، وليست بديلاً عن نظام تحكيم رسمي، لكنها تبني منطقًا قريبًا من TES وGOE وPCS لتطوير البرنامج لاحقًا.

## الخطوات التالية
- إضافة كشف أكثر دقة لمراحل الحركة حسب السرعة والارتفاع
- دعم التحليل المباشر بالكاميرا
- توسيع قاعدة العناصر ومستوياتها
- تحسين نموذج التقدير ليقترب أكثر من الجداول الرسمية
